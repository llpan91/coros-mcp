3. 心率漂移分析 (Cardiac Drift)

长时间匀速跑中, 心率逐渐上升的现象称为心率漂移。漂移率 = (后半段HR - 前半段HR) / 前半段HR x 100%。漂移>5%提示脱水或有氧基础不足。
